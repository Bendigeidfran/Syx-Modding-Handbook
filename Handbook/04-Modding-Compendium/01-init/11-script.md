# init/script

The `init/script` folder is empty in vanilla. The game sets up a path to it, but no code reads files from it, so there's nothing to add here.

Don't confuse it with the `script` folder that holds code mods. A code mod's `.jar` files go in `script` directly inside the mod's version folder, such as `V71/script/`, next to `assets` rather than inside it.

## At a glance

| | |
|---|---|
| **Location** | `assets/init/script/` |
| **Files** | None in vanilla |
