# init/world

The `init/world` folder covers the world map outside your city: the buildings you can put up in the regions you hold, the workforce that runs them, and settings for how the map is generated and coloured.

The folder holds only sub-folders:

| Sub-folder | What it does |
|---|---|
| [`building/`](01-building.md) | Defines region buildings, sorted into categories. |
| [`config/`](02-config/00-config.md) | One-off settings for the world map. |
| [`point/`](03-point.md) | Defines the points region buildings use, such as workforce. |

The text folder also has `text/world/industry/MONEY.txt`, but the game doesn't read that folder.
