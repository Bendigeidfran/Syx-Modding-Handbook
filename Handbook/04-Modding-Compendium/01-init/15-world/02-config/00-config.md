# init/world/config

These files hold one-off settings for the world map. The game loads each one by its exact name, and each has its own format. To change a setting, put a file of the same name in your mod, as described under [Changing a vanilla file](../../../../02-Getting-Started.md#changing-a-vanilla-file).
