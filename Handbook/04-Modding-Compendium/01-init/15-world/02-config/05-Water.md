# init/world/config/Water.txt

`Water.txt` sets the colours of water on the world map.

## At a glance

| | |
|---|---|
| **Location** | `assets/init/world/config/Water.txt` |
| **Adding new files** | No. Only this file is read. |

## Tags

### COLOR_OCEAN

The colour of the ocean.

| | |
|---|---|
| **Type** | Colour |
| **Required** | Yes |

```text
COLOR_OCEAN: 107_137_186,
```

### COLOR_OCEAN_SHORE

The colour of the ocean's shore.

| | |
|---|---|
| **Type** | Colour |
| **Required** | Yes |

```text
COLOR_OCEAN_SHORE: 208_212_129,
```

### COLOR_LAKE

The colour of lakes.

| | |
|---|---|
| **Type** | Colour |
| **Required** | Yes |

```text
COLOR_LAKE: 113_133_140,
```

### COLOR_LAKE_SHORE

The colour of a lake's shore.

| | |
|---|---|
| **Type** | Colour |
| **Required** | Yes |

```text
COLOR_LAKE_SHORE: 101_119_63,
```
