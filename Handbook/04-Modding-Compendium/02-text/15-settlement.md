# text/settlement

These files hold the wording of the things defined in [`init/settlement`](../01-init/12-settlement/00-settlement.md). Each sub-folder matches one there, and its page explains the format.

## At a glance

| | |
|---|---|
| **Location** | `assets/text/settlement/` |

| Sub-folder | Holds | Format |
|---|---|---|
| `environment/` | The name, description and subjects' opinions for each effect. | [Environment effects](../01-init/12-settlement/01-environment.md#the-text-file) |
| `fence/` | The name and description of each fence. | [Fences](../01-init/12-settlement/02-fence.md#the-text-file) |
| `floor/` | The name and description of each road. Floors that aren't roads have none. | [Floors](../01-init/12-settlement/03-floor.md#the-text-file) |
| `fortification/` | The name and description of each fortification. | [Fortifications](../01-init/12-settlement/04-fortification.md#the-text-file) |
| `structure/` | The names of each building material, including its walls and ceilings. | [Structures](../01-init/12-settlement/05-structure.md#the-text-file) |
