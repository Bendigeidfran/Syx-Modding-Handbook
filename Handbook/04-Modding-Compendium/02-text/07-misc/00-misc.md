# text/misc

This folder holds text that doesn't belong to anything in `init`: the advisor's messages, the quotes on the loading screen and the serial killer event. Each file here has its own format.

The game loads each file by its exact name, so a new file with a different name is ignored. The exception is `serialKiller/`, where a new file adds a new killer.
