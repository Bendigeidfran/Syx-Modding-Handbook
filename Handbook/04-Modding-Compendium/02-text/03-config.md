# text/config

This folder holds one file, the names and descriptions of crimes and punishments. They're defined in [`init/config/LAW.txt`](../01-init/03-config/07-LAW.md), and that's the page that explains the format.

## At a glance

| | |
|---|---|
| **Location** | `assets/text/config/` |
| **Files** | `LAW.txt` only |
| **Required** | Yes |
| **Tags** | `CRIMES` and `PUNISHMENTS`, described on the [init/config/LAW.txt page](../01-init/03-config/07-LAW.md) |

This is the start of the vanilla `LAW.txt`:

```text
CRIMES: {
	OTHER: {
		NAME: "Other",
		NAMES: "Others",
		TITLE: "Other",
		TITLES: "Others",
```
