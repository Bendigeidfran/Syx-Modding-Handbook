# text

The `text` folder holds the words the player reads: names, descriptions, dialogue, event text, the in-game wiki and the game's general vocabulary. Many `init` files have a partner here with the same name, which supplies the name and description for whatever the `init` file defines.

In the game's data, the folder is at `data/assets/text`. In a mod, it goes in `V71/assets/text`.

Its sections follow the game's sub-folders. Many of them are short, because a text file's tags are described with the `init` file it belongs to.
