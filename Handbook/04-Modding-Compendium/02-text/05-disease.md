# text/disease

These files hold the name and description of each disease. The disease itself is defined by the file of the same name in [`init/disease`](../01-init/04-disease.md), and that's the page that explains the format.

## At a glance

| | |
|---|---|
| **Location** | `assets/text/disease/` |
| **Files** | One `.txt` file per disease, named after its file in `assets/init/disease/` |
| **Required** | Yes, for every disease |
| **Tags** | Described under [The text file on the init/disease page](../01-init/04-disease.md#the-text-file) |

This is the whole of the vanilla `BLEEDING_FEVER.txt`:

```text
NAME: "The bleeding fever",
DESC: "The bleeding fever is a very deadly disease that has been around for eons. It's very rare, and thought extinct on many occasions. Victims of this excruciating affliction suffer from a delirium inducing fever and increasingly dry and brittle skin, which will rip at the slightest touch. Simply turning in bed can lead to a gruesome death.",
```
