# text/resource

These files hold the name and description of each resource. The resource itself is defined by the file of the same name directly in [`init/resource`](../01-init/09-resource/01-resource-file.md), and that's the page that explains the format. The sub-folders of `init/resource` have no text files.

## At a glance

| | |
|---|---|
| **Location** | `assets/text/resource/` |
| **Files** | One `.txt` file per resource, e.g. `BREAD.txt` |
| **Required** | Yes, for every resource |
| **Tags** | Described under [The text file on the resource page](../01-init/09-resource/01-resource-file.md#the-text-file) |

This is the whole of the vanilla `BREAD.txt`:

```text
NAME: "Bread",
NAMES: "Bread",
DESC: "Bread is a staple food, produced by bakeries.",
```
