# text/world

These files hold the wording of the things defined in [`init/world`](../01-init/15-world/00-world.md). Its pages explain each format.

## At a glance

| | |
|---|---|
| **Location** | `assets/text/world/` |

| Sub-folder | Holds | Format |
|---|---|---|
| `building/` | The names and descriptions of region buildings, in the same category folders as `init`. Generated buildings and `_CAT.txt` have none. | [init/world/building](../01-init/15-world/01-building.md#the-text-file) |
| `point/` | The name and description of each point. | [init/world/point](../01-init/15-world/03-point.md#the-text-file) |

## Notes

### A vanilla folder the game doesn't read

`industry/` holds one file, `MONEY.txt`, but the game doesn't read that folder.
