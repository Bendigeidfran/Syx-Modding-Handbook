# text/religion

These files hold the name, description and deity of each religion. The religion itself is defined by the file of the same name in [`init/religion`](../01-init/08-religion.md), and that's the page that explains the format.

## At a glance

| | |
|---|---|
| **Location** | `assets/text/religion/` |
| **Files** | One `.txt` file per religion, named after its file in `assets/init/religion/` |
| **Required** | Yes, for every religion |
| **Tags** | Described under [The text file on the init/religion page](../01-init/08-religion.md#the-text-file) |

This is the start of the vanilla `AMINION.txt`:

```text
NAME: "Aminionism",
DEITY: "Aminion",
DESC: "Aminion, the lord of chaos promotes submission and his temples accepts human sacrifices (prisoners).",
```
