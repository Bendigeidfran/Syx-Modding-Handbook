# text/race

These files hold the wording tied to races: each race's own names, plus the biographies, speech and reviews that a race file points to. A file directly in this folder belongs to the race of the same name.

## At a glance

| | |
|---|---|
| **Location** | `assets/text/race/` |

| File or sub-folder | Holds | Format |
|---|---|---|
| `<RACE>.txt` | A race's names, descriptions and the words its members use. | [The text file on the race file page](../../01-init/07-race/01-race-file.md#the-text-file) |
| `bio/` | Subjects' biographies and opinions. | [text/race/bio](01-bio.md) |
| `king/` | What AI rulers say. | [text/race/king](02-king.md) |
| `nobility/` | Names of noble offices. The game doesn't read these. | [init/race/nobility](../../01-init/07-race/05-nobility.md) |
| `raider/` | Raiders' messages and names. | [text/race/raider](03-raider.md) |
| `tourist/` | Tourists' reviews. | [text/race/tourist](04-tourist.md) |
| `trait/` | The name and wording of each trait. | [init/race/trait](../../01-init/07-race/07-trait.md) |
| `worldcamp/` | The wording of each world camp. | [init/race/worldcamp](../../01-init/07-race/08-worldcamp.md) |
