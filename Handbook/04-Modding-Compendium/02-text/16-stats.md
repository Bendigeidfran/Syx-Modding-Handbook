# text/stats

These files hold the wording of the things defined in [`init/stats`](../01-init/13-stats/00-stats.md). Its pages explain each format.

## At a glance

| | |
|---|---|
| **Location** | `assets/text/stats/` |

| File or sub-folder | Holds | Format |
|---|---|---|
| `NAMES.txt` | The names and descriptions of most stats. | [text/stats/NAMES.txt](../01-init/13-stats/07-NAMES.md) |
| `damage/` | The name of each damage type, and of its three values. | [init/stats/damage](../01-init/13-stats/02-damage.md#the-text-file) |
| `dynamicBoost/` | The name and description of each value. | [init/stats/dynamicBoost](../01-init/13-stats/03-dynamicBoost.md#the-text-file) |
| `need/` | The names of each need. | [init/stats/need](../01-init/13-stats/06-need.md#the-text-file) |

Equipment has no text files, because it takes its wording from its resource.
