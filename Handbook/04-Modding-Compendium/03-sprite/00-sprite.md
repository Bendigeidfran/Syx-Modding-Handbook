# sprite

The `sprite` folder holds the game's images as `.png` files: character and animal sprite sheets, icons, room and map graphics, fonts and interface art. Files in `init` usually refer to images here by name, without the `.png` extension.

In the game's data, the folder is at `data/assets/sprite`. In a mod, it goes in `V71/assets/sprite`.
