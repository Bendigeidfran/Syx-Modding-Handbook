# sprite/ui

This folder holds the art of the game's interface: the frames of windows and panels, the boxes behind their titles, the clock and speed buttons, the mouse pointer, the markings drawn while you plan and place things, the icons of titles and game modes, and the symbols on faction banners and army divisions. It also holds `Colors.txt`, which sets the colours of the interface's text, bars and map markings.

In the game's data, the folder is at `data/assets/sprite/ui`. In a mod, it goes in `V71/assets/sprite/ui`.

## How these files work

No tag names these files. The game asks for each one by name, and there's no way to add more: a new file in this folder is never read.

| File | Holds |
|---|---|
| `Colors.txt` | The interface's colours |
| `Cons.png` | The markings drawn while planning and placing |
| `Decor.png` | Ornaments, decorated borders, sliders and the mouse pointer |
| `DivisionSymbols.png` | The symbols on army divisions |
| `FactionBanners.png` | The symbols on faction banners |
| `Panels.png` | The frames of windows and panels |
| `Specials.png` | The clock, the speed buttons and the background of the build panel |
| `TitleBox.png` | The boxes behind window titles, and the close button |
| `Titles.png` | The icons of titles and game modes |

Most of these sheets have their sprites in colour in the left half and a matching normal map in the right half, which the game uses to light them. The game cuts each sheet by position, so a sprite has to stay inside its cell. The frames vanilla draws around the cells are never read. `FactionBanners.png` and `DivisionSymbols.png` work differently: they have no normal map, and the game reads only which pixels are black.

Each page gives the exact layout and shows the vanilla image: move over a sprite to see what it's for. The tooltip gives its name in the game's code, then its left edge, top edge, width and height in pixels. The names are only labels, and you don't write them in any file. A sprite with ` normal` after its name is that sprite's normal map.

## Changing a file

The simplest way to make a sheet is to copy the vanilla image from `base/data.zip` and paint over it. Give your copy the same name and put it in `V71/assets/sprite/ui/`. The game uses the first copy of an image it finds, looking in your mods before vanilla, so two mods that each change the same image can't be combined. See [What isn't layered](../../../02-Getting-Started.md#what-isnt-layered).

`Colors.txt` is different: like the files in `init`, it's layered over the vanilla file tag by tag. See [Changing a vanilla file](../../../02-Getting-Started.md#changing-a-vanilla-file).
