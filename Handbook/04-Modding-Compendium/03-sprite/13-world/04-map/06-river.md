# sprite/world/map/River

`River.png` ships with the game at 576 by 172 pixels, but no code opens it, so changing it has no effect. Rivers on the world map are drawn from [`RiverBig.png`](07-riverbig.md) and [`RiverSmall.png`](08-riversmall.md).

The page has no image, because the sheet is never used.
